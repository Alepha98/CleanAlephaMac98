## Заметки
- Скриншоты из агентской песочницы недоступны (TCC); тема проверена через `defaults` после реальных кликов.
- Ряд «Проверка» легко промахнуть в скролле сайдбара — для UI-автомации надёжнее меню **Разделы**.
