# CleanAlephaMac98 – тестовая документация

Версия приложения, под которую писалось: **1.1.5**.  
Лог: `~/Library/Logs/CleanAlephaMac98.log`  
Язык интерфейса смотри в `defaults read com.alepha98.CleanAlephaMac98 cam98.language` (`system` / `ru` / `en`).  
Последний открытый раздел: `cam98.module`.

Цель прогона: выловить зависания, пустые сканы, ложные «можно очистить», порчу логинов, удаление защищённых папок, мёртвые кнопки, кривой DMG, расхождение RU/EN.

Как читать лог во время теста:

```bash
tail -f ~/Library/Logs/CleanAlephaMac98.log
```

Ожидаемые строки:

- `scan start smart` / `scan done smart items=N`
- `scanLive start pulse` → `pulse junk apps=N used=…` → `pulse tabs Safari ms=…` → `scanLive done pulse items=N`
- `osascript timeout` – вкладки не прочитались, RAM-карточка всё равно должна быть
- `osascript err (-1743)` – нет Автоматизации, не зависание
- `auto done` – сработал таймер автоочистки, не ручной скан

Перед каждым прогоном: `killall CleanAlephaMac98`; открыть из `~/Applications`. Не тестировать из папки `dist/` в репо – это не установленная копия.

## 0. Стенд

- Mac на Apple Silicon и, если есть, Intel.
- macOS 14+.
- Пользователь без полного доступа к диску (первый прогон) и с ним (второй).
- Safari запущен с 2+ вкладками.
- Chrome: обычное окно **и** отдельно сессия `--no-startup-window` (фон без окна – не должен вешать Память).
- Telegram / Сообщения – по возможности.
- Colima / Parallels / Gradle / Simulator – если папки есть, они в «Не трогаем».
- Автоочистка выключена, пока не дойдёшь до раздела Обслуживание.

Чеклист окружения записать: чип, macOS, FDA да/нет, какие браузеры живые.

## 3. Слои очистки

Для каждого: Системный мусор, Почта, Корзины, Остатки, Большие файлы, Браузеры, Разработка, Мессенджеры.

Общий шаблон (подставить имя слоя = `L-*`):

1. Зайти в слой без скана – сфера + «Сканировать», не чужие карточки.
2. Сканировать – только карточки этого слоя.
3. Карточка 0 Б не показывается.
4. Правый клик → Показать в Finder (реальный путь).
5. Правый клик → Не трогать эту папку – исчезает из следующих сканов, появляется в Обслуживании.
6. Очистить одну карточку – остальные целы.
7. Стоп во время очистки – уже удалённое не откатывается, оставшееся на месте.
8. Повторный скан – размеры пересчитаны.

Специфика:

| ID | Слой | Дополнительно |
| --- | --- | --- |
| J1 | Мусор | `~/Library/Logs`, Saved Application State. Не `/var/log`. |
| M1 | Почта | Только загрузки/кэш, не `~/Library/Mail` целиком. |
| T1 | Корзина | По умолчанию выкл. Очистить корзину – отдельный тон кнопки. Файл из корзины после очистки не восстанавливается. |
| O1 | Остатки | Только приложения, которых нет в `/Applications` и `~/Applications`. Не трогать живой Chrome. |
| B1 | Большие | По умолчанию выкл. Порог ~80 МБ. Не заходить в `.git`, `node_modules`, `.colima`. |
| R1 | Браузеры | Есть диск-кэш. **Нет** Cookies, Login Data, Web Data. После очистки сайт не разлогинивает. |
| R2 | Chrome Default + Profile 1 | Отдельные карточки, логины целы. |
| R3 | Safari сеть | WebsiteDataStore, не контейнер сессий. |
| D1 | Dev | npm/SwiftPM/DerivedData. **Нет** `.gradle`, CoreSimulator, DeviceSupport. |
| G1 | Telegram | Медиа вкл, история выкл. Аккаунт находится сам, не хардкод. |
| G2 | Сообщения | Без FDA почти пусто. С FDA – вложения, по умолчанию выкл. |

Невозможное / запретное:

- Выделить и удалить Login Data – карточки быть не должно.
- Скан удаляет Colima/Parallels/Photos – провал.
- «Очистить» на Памяти убивает Chrome – провал.

## 4. Память (главный регресс)

Память – тот же экран, что Умный скан: сфера, **Сканировать**, карточки. Не отдельная портянка и не автозапуск при открытии.

| ID | Сценарий | Ожидание | Лог |
| --- | --- | --- | --- |
| P1 | Открыть Память | Сфера, кнопка Scan/Сканировать, UI кликабелен | нет `scanLive` до клика |
| P2 | Сканировать | Карточка давления RAM (занято/всего), процессы, опционально вкладки | `scanLive start pulse` … `scanLive done pulse items≥1` |
| P3 | Chrome без окна (`--no-startup-window`) | Скан не висит, Chrome не всплывает новым окном | `pulse skip Google Chrome` или tabs=0, **нет** timeout > 3 с на Chrome |
| P4 | Safari с вкладками + Автоматизация разрешена | Вкладки в карточках, «Показать вкладку» в меню карточки, Safari не закрывается | `pulse tabs Safari … tabs>0` |
| P5 | Автоматизация запрещена | RAM и процессы есть, баннер про Автоматизацию, нет вечного спиннера | `osascript err (-1743)` |
| P6 | Стоп во время вкладок | Не мёртвый UI, можно уйти в другой раздел | `scanLive` обрывается, кнопки живые |
| P7 | Очистить | Кнопка неактивна (это не Free RAM) | нет `Janitor` по процессам |
| P8 | Рестарт на pulse | Снова сфера, **не** автозавис | процесс не unresponsive |
| P9 | Цифра в шапке | Занятая RAM, не сумма RSS всех хелперов | used ≈ Activity Monitor |
| P10 | Сайдбар | После скана размер ≈ занятая RAM | не 0 и не мусорный двойной счёт |

Негатив: 200 вкладок Chrome; Safari из Cryptex (`/System/Volumes/Preboot/...`); только Helper-процессы; своп > 1 ГБ – статус «Уже своп».

## 12. Невозможные / абсурдные

- Скан при вынутом диске (только сеть) – не падать.
- Удалить карточку, путь которой уже стёрт вручную – «уже не было», не краш.
- Имя файла с эмодзи / пробелами / NFC в кэше.
- 0 байт свободных – очистка не зависает навсегда.
- Два окна приложения – у нас одно; не плодить.
- `defaults delete cam98.module` – старт на Умном скане.
- Лог 100 МБ – Open log не вешает TextEdit навечно (открывается как есть).
- Язык en, копирайты и About на английском, без калек «Walk caches».

Для каждого ID: Pass / Fail / Skip, время, строка лога, скрин если fail.

Порядок: S1–S8 → P1–P10 (Память) → U1–U10 → слои выборочно R1–R3, D1, G1 → C1–C8 → A1–A6 → Dsk → Svc → X → I → N → Z → CLI.

## 14. Автоматизация (обязательный префлайт)

Бинарник: `CleanAlephaMac98.app/Contents/MacOS/CleanAlephaMac98` или `.build/.../CleanAlephaMac98`.

| Флаг | Что делает | Успех |
| --- | --- | --- |
| `--qa-pulse` | RAM + `ps` + вкладки, без окна, пишет лог, `exit 0` | stdout `qa-pulse ok`, карточки RAM ≥ 1, **не висит** |
| `--qa-protect` | Adware / agents / hosts | `qa-protect ok`, наш агент не selected |
| `--qa-startup` | LaunchAgents + login items | `qa-startup ok`, наш агент `kind-advice=true` |
| `--qa-keep` | Каталог «не трогаем» | `qa-keep ok`, пути Colima/Photos и т.д. |
| `--qa-smart` | Все слои Scanner, ловит утечки Keep и Login Data | `leaks=0`, нет `qa smart LOGIN` |
| `--module pulse --auto-scan` | UI: открыть Память и сразу сканировать | в логе `scanLive pulse ram items≥1` за < 8 с |
| `--auto` | Фоновая автоочистка | только кэши, `auto done` |

Скрипты:

```bash
zsh scripts/qa-probe.sh
zsh scripts/qa-run.sh
tail -f ~/Library/Logs/CleanAlephaMac98.log
```

Не гонять `--qa-*` и GUI одновременно на одном бинарнике.

## 25. Матрица разделов × действия

Для **каждого** cleanup-модуля: `smart junk mail trash leftovers large browsers dev messengers pulse protect startup`.

Действия: открыть / Scan / Stop / Safe / Deselect / Clean / ⌘R / правый клик / язык RU/EN / рестарт на этом модуле.

Ожидание:

- `space` и `tools` – **нет** Scan как у слоёв; диск = кольцо, tools = расписание/исключения/лог.
- `pulse` – Scan да, Clean нет.
- `protect` – Scan да, Clean только не-advice.
- `startup` – Scan да, Clean только чужие агенты/login items.
- Smart не выставляет `hasScanned` на live-модули.

## 26. Что смотреть в логе (словарь)

| Строка | Смысл |
| --- | --- |
| `pulse memory begin` | вошли в RAM |
| `pulse ps begin` / `pulse ps bytes=` | `ps` жив, пайп не встал |
| `pulse ps timeout` | `ps` убит по 5 с – RAM-карточка всё равно |
| `pulse junk apps=N used=` | карточки процессов |
| `pulse skip NAME – not running with a window` | браузер не дёргаем |
| `pulse tabs NAME ms=` | AppleScript, ms не должен быть минутами |
| `osascript timeout after Ns` | вкладки скип, UI жив |
| `osascript err (-1743)` | нет Автоматизации |
| `osascript err (-1712)` | AppleEvent timeout |
| `scanLive start pulse` / `scanLive pulse ram items=` | UI уже может показать карточки |
| `scanLive pulse tabs extras=` | вкладки догнались |
| `scan start smart` / `scan done smart` | умный скан |
| `qa smart LEAK` / `qa smart LOGIN` | **стоп-фактор** |
| `auto done` | агент, не UI |
